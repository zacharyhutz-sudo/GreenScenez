# GreenScenez — Website Concept Brand Guide

## Identity

- **Name:** GreenScenez Landscape Management LLC
- **Positioning:** Good ground. Great first impressions.
- **Voice:** Warm, grounded, precise, quietly confident. Local first, never flashy or inflated.
- **Primary Pine:** `#193D2C`
- **Deep Forest:** `#113020`
- **Accent Leaf:** `#D2EF8C`
- **Sage:** `#8CBF8A`
- **Off-white:** `#F5F5EB`
- **Text:** `#162C20`

## Type system

- **Display/Headings:** Manrope, 800, tight letter-spacing.
- **Body/UI:** DM Sans, 400–800.
- Browser fallback: system UI sans-serif. Web fonts are loaded from Google Fonts.

## Logo assets

- `assets/wordmark.svg` — proposed concept wordmark, typographic + leaf mark.
- `assets/logo-mark.svg` — proposed square leaf emblem.
- `assets/favicon.svg` — emblem for browser tabs.

**Note:** These are proposed redesign concepts, not necessarily the company's existing approved logo. The official identity is an olive-green tree logo with name beneath it, visible in Madison County Chamber listings. Seek the business's approval before public launch.

## Art direction

Use clean open space, pine-green panels, light green highlights, abstract topographical contours, simple botanical motifs. Do **not** use AI-generated project photographs. Only use genuine, authorized photos of completed GreenScenez projects, ideally sourced from the company or its Facebook page and explicitly approved for reuse. The current concept intentionally relies on vector graphic motifs until authorized company photos are available.
